## КОРОТКО

### ❌ СТАРЫЙ МЕТОД (ТЫ БЫЛ ПРАВ):
```cpp
// Чекал через СКОРОСТЬ - НЕ ПРАВИЛЬНО!
if (speed <= 0.1f && is_scoped)
    return 100; // Максимальная точность

// Использовал local_data (устаревает)
float spread = local_data->m_spread;
float inaccuracy = local_data->m_inaccuracy;
```

**Почему это говно:**
- Скорость не равно точность (контр-страф: speed > 0, но точность высокая)
- После приземления: speed = 0, но inaccuracy ВЫСОКАЯ = мисс
- local_data обновляется не каждый тик = неточно

### ✅ НОВЫЙ МЕТОД (ИЗ UNKNOWNCHEATS):
```cpp
// Берём ПРЯМО ИЗ ОРУЖИЯ (не через скорость!)
float spread = weapon->get_spread();
float inaccuracy = weapon->get_inaccuracy();

// Генерируем 128-256 лучей с правильным spread
for (int i = 0; i < 128; i++) {
    vec3_t spread_dir = generate_with_cs2_spread(inaccuracy, spread, i);
    
    // Трассируем луч по хитбоксам
    if (ray_hits_hitbox(spread_dir))
        hits++;
}

// Процент попаданий = хитшанс
return (hits / 128) * 100;
```

**Почему это правильно:**
- ✅ Использует РЕАЛЬНЫЙ spread из оружия (всегда актуальный)
- ✅ НЕ зависит от скорости напрямую (inaccuracy уже учитывает движение)
- ✅ Trace-based: реально проверяет попадёт ли пуля
- ✅ Работает в ЛЮБОЙ ситуации (контр-страф, прыжок, присед, ...)

## КАК ЭТО РАБОТАЕТ

### 1. Spread в CS2 = два компонента:

**Inaccuracy (динамический):**
- От движения: бег = 45, стоя = 1, присел = 0.5
- От stance: в воздухе = 100, на земле = 1
- От скопа: unscoped AWP = 150, scoped = 0.5
- `weapon->get_inaccuracy()` даёт текущее значение

**Spread (статический):**
- Базовый spread оружия
- AK-47 = 7.0, AWP = 0.5, P90 = 5.5
- `weapon->get_spread()` даёт значение

### 2. Генерация spread направления:

```cpp
// CS2 метод: ДВА независимых круга

// Круг 1: Inaccuracy (от движения/stance)
float angle1 = random(0, 360°);
float radius1 = random(0, 1) * inaccuracy;
float x1 = cos(angle1) * radius1;
float y1 = sin(angle1) * radius1;

// Круг 2: Spread (от оружия)
float angle2 = random(0, 360°);
float radius2 = random(0, 1) * spread;
float x2 = cos(angle2) * radius2;
float y2 = sin(angle2) * radius2;

// СУММИРУЕМ (не умножаем!)
float total_x = x1 + x2;
float total_y = y1 + y2;

// Применяем к направлению
vec3_t direction = forward + (right * total_x) + (up * total_y);
```

### 3. Трассировка:

```cpp
// Для каждого луча проверяем попадёт ли он в хитбоксы
for (hitbox in hitboxes) {
    if (ray_intersects_capsule(ray_direction, hitbox))
        return true; // ХИТ!
}
return false; // МИСС
```

### 4. Итог:

```
hitchance = (попаданий / всего лучей) * 100%

Пример:
128 лучей → 95 попали → hitchance = 74%
```

## ЧТО ТЕСТИРОВАТЬ

1. **Контр-страф с AK:**
   - Зажми A, потом быстро D
   - В момент остановки speed ещё > 0
   - ДОЛЖЕН стрелять (inaccuracy низкая)

2. **После прыжка Scout:**
   - Прыгни, приземлись
   - НЕ должен стрелять 2 тика (landing check)
   - После 2 тиков: проверит hitchance
   - Если заскоплен и стоишь → стреляет

3. **Двигаешься боком M4A1:**
   - Бежишь вбок (speed = 200)
   - inaccuracy высокая
   - hitchance ~10-20%
   - НЕ должен стрелять

4. **Присел, стоишь, AWP, заскоплен:**
   - Все условия идеальные
   - hitchance = 100%
   - Должен стрелять мгновенно
